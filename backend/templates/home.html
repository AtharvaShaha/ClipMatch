The ClipMatch Pipeline

Our 4-stage matching process

1

Frame Extraction

Extract 20 evenly-spaced frames from your query clip using OpenCV. Each frame is resized to 320×240 for fast processing.

Input: MP4, AVI, MKV, MOV, WEBM (5-60 sec)
→
2

Feature Hashing

Compute three perceptual hashes (pHash, dHash, wHash) per frame. Also extract color averages and brightness for multi-signal comparison.

64-bit fingerprint per hash algorithm
→
3

Library Comparison

Compare clip hashes against all indexed reference videos using vectorized Hamming distance. Multi-threaded across 6 workers for parallel processing.

Processes 60+ references in ~1 second
→
4

Confidence Scoring

Weighted formula combining hash match ratio, color similarity, average distance, and temporal consistency. Returns the best match with exact timestamps.

Minimum 45% confidence threshold
